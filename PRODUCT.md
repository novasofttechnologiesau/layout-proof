# Product

## Register
product

## Users
Web developers checking responsive layouts locally and in continuous integration. They need actionable evidence: the affected viewport, an exact selector, a screenshot, and a clear description of what to inspect.

## Product Purpose
Layout Proof is a standalone URL-based layout checker. It produces local HTML and JSON reports without requiring adoption of a hosted platform. Success is reproducing a layout problem quickly and explaining the limits of each automated check.

## Brand Personality
Plain, precise, practical. The report follows the developer-tool style confirmed for this project: readable light and dark themes, keyboard-accessible controls, screenshots and exact selectors.

## Anti-references
No marketing dashboard, decorative charts, hero metrics, or repeated ornamental cards. Do not turn heuristic warnings into accessibility certification claims.

## Design Principles
Prioritize findings over summaries. Keep reproduction details next to each finding. Separate execution failures from detected problems. Make clean results as understandable as broken ones.

## Accessibility & Inclusion
Semantic headings and disclosures, visible focus, sufficient contrast, responsive reflow, and no required animation. Warnings use text rather than color alone.
