# Report design

A developer reviews a downloaded report beside their editor during ordinary desk work. Use the operating system's light/dark preference and system fonts so the evidence stays comfortable in either environment.

Restrained neutral surfaces with muted violet links, semantic text status, and thin structural dividers. A single reading column with a compact run index, native disclosure sections, and screenshots that fit the available width. Long URLs and selectors wrap rather than widening the page. No external fonts, scripts, analytics, or assets are loaded by the report. Use OKLCH tokens and visible keyboard focus.
